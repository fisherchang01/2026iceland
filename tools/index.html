🚀 典型工作流

步驟 1：準備 PAT - GitHub Settings → Developer settings → Personal access tokens，生成新 token（勾選 repo 權限）。第一次上傳時編輯器會跳出輸入框，之後存在瀏覽器不用再輸入

步驟 2：打開編輯器 - 選擇上面的編輯器之一，會自動讀取 GitHub 上的最新內容

步驟 3：編輯 - 左欄選分類 → 中欄改欄位、增刪搬移項目與 block → 右欄看即時預覽

步驟 4：本地保存 - 點「💾 本地保存」存進瀏覽器草稿，關掉也不會遺失

步驟 5：上傳 - 點「⬆️ 上傳到 GitHub」，通過 Guard 檢查後會跳出 diff 摘要供確認

⏱️ 重要提示：GitHub Pages 部署需要 1–2 分鐘。若修改後網站沒有立即更新，請硬重新整理（Ctrl+Shift+R / Cmd+Shift+R）。手機上請用 PWA 或無痕視窗確認。

⚠️ 不要同時兩個人編輯：編輯器是「讀整份 → 改 → 寫整份」，後上傳的會覆蓋先上傳的。

✨ 編輯器特性

✓ 零部署成本 - 無需本地開發環境，直接在瀏覽器中使用

✓ 即時預覽 - 右側面板即時顯示編輯效果

✓ Block 編輯 - 小標題、文字、圖片可自由排序，順序即版面順序

✓ 直接上傳照片 - 在項目裡選本機檔案即可，自動縮圖、命名、commit 並掛上，不必先線下處理

✓ 圖片挑選器 - 三段篩選（未使用／本頁已用／全部），同時掃描體驗頁與工具頁，不會把另一頁在用的圖列成未使用

✓ 本地草稿 - 存在瀏覽器，關掉也不會遺失；有未上傳修改的分類會標上 ●

✓ 上傳 Guard - 五道檢查加 diff 摘要確認，防止一次上傳把資料清空

✓ 文字標記 - 支援粗體、斜體、換行、指定顏色

✓ GitHub 整合 - 一鍵上傳，無需命令列
