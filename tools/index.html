🚀 典型工作流

步驟 1：準備 - 前往 GitHub Settings → Developer settings → Personal access tokens 生成新 token（勾選 repo 權限）

步驟 2：打開編輯器 - 選擇上面的編輯器之一

步驟 3：認證 - 在右上角粘貼 GitHub PAT

步驟 4：讀取內容 - 點擊「讀取 GitHub」按鈕加載網站內容

步驟 5：編輯 - 選擇分類、選擇項目、編輯文本、點擊「保存此項目」

步驟 6：上傳 - 所有編輯完成後，點擊「上傳到 GitHub」推送修改

⏱️ 重要提示：GitHub Pages 部署需要 1-2 分鐘。如果修改後網站沒有立即更新，請硬刷浏览器（Ctrl+Shift+R 或 Cmd+Shift+R）。
