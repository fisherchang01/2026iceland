# images/

圖片資料夾分工、尺寸規格與命名規則，已整合到 **[docs/IMAGES.md](../docs/IMAGES.md)**，請以該文件為準。

快速對照：

| 資料夾 | 用途 |
|---|---|
| `banners/` | 每日卡片封面 + 首頁 hero |
| `routes/` | 每日路線圖 |
| `spots/thumb/` | 景點縮圖 |
| `spots/medium/` | 景點大圖（兼燈箱） |
| `catalog/` | 體驗頁 + 工具頁的分類封面與內文圖 |
| 根目錄 | 只放 `app-icon-*` 與本檔 |
