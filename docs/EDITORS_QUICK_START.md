# 第一阶段 · 快速参考卡

## 🎯 30 秒快速开始

### 1️⃣ 上传 HTML 文件
```
放入 2026iceland/tools/ 文件夹：
- travel-editor.html
- other-editor.html
```

### 2️⃣ 生成 GitHub PAT
GitHub Settings → Developer settings → Personal access tokens → 生成新 token（勾选 `repo`）

### 3️⃣ 打开编辑器
访问：`https://fisherchang01.github.io/2026iceland/tools/travel-editor.html`

### 4️⃣ 粘贴 PAT 并读取
1. 在右上角粘贴 GitHub PAT
2. 点击「讀取 GitHub」

### 5️⃣ 开始编辑
1. 左侧选择分类
2. 中间选择项目
3. 下方编辑文本
4. 右侧实时预览
5. 点击「保存此項目」

### 6️⃣ 上传
点击「上傳到 GitHub」推送所有修改

## 💾 数据存储

### localStorage 中的草稿

编辑器自动保存在浏览器本地，格式：

```javascript
// 查看草稿（在浏览器控制台输入）
JSON.parse(localStorage.getItem('travel_drafts'))

// 输出示例
{
  "0_0": { "title": "新標題", "detail": "新描述" },
  "0_1": { "title": "...", "detail": "..." },
  ...
}
```

### localStorage 清空

```javascript
// 删除草稿（清空本地缓存）
localStorage.removeItem('travel_drafts');  // 删除体验草稿
localStorage.removeItem('other_drafts');   // 删除其他草稿
```

## 🎯 支持的编辑标记

在描述文本中可使用以下标记：

| 标记 | 用途 | 示例 | 预览 |
|------|------|------|------|
| `/n` | 换行 | `第一行/n第二行` | 第一行<br>第二行 |
| `{bold}..{/bold}` | **粗体** | `{bold}重点{/bold}` | **重点** |
| `{italic}..{/italic}` | *斜体* | `{italic}注{/italic}` | *注* |
| `{#RRGGBB}..{/color}` | 颜色 | `{#ff0000}红{/color}` | <span style="color:#ff0000">红</span> |

**示例**：
```
这是一个{bold}非常重要{/bold}的提示。/n
请注意{italic}以下{/italic}内容：
{#0066cc}信息{/color}
```

## 🔐 安全提示

### GitHub PAT 安全

- ⚠️ **不要在公开场所共享 PAT**
- ⚠️ **PAT 仅在当前浏览器中存储**（localStorage）
- ⚠️ **关闭浏览器后 PAT 仍保留在本地**
- ✓ 建议：经常删除旧 PAT，定期生成新的
- ✓ 建议：在共享电脑上使用后清空浏览器数据

### 清空 PAT 的方法

```javascript
// 方法 1：编辑器中
// 打开编辑器 → 清空 PAT 输入框 → 回车

// 方法 2：浏览器控制台
localStorage.removeItem('github_pat');

// 方法 3：清空所有本地数据
localStorage.clear();
```

## 🚀 常见工作流

### 工作流 A：快速编辑单个项目

```
1. 打开编辑器
2. 讀取 GitHub ← 已有 PAT 自动完成
3. 选择分类 & 项目
4. 编辑描述
5. 保存此項目 (保存到 localStorage)
6. 上傳到 GitHub ← 推送所有草稿
```

**耗时**：~5 分钟（含 GitHub 部署）

### 工作流 B：批量编辑多个项目

```
1. 打开编辑器
2. 讀取 GitHub
3. 编辑项目 A → 保存
4. 编辑项目 B → 保存
5. 编辑项目 C → 保存
6. 上傳到 GitHub ← 一次推送所有修改
```

**耗时**：~10 分钟

### 工作流 C：草稿保存和恢复

```
情境：多次编辑，稍后上传

1. 编辑项目 A → 保存此項目
2. 浏览器关闭
3. 重新打开编辑器
4. 草稿自动恢复 ✓
5. 继续编辑或直接上傳
```

**提示**：localStorage 会一直保留草稿，直到上传或手动清空

## 🔍 故障排查速查表

| 问题 | 原因 | 解决方案 |
|------|------|--------|
| 「未認證」状态 | PAT 未输入或无效 | 重新粘贴 PAT，检查是否过期 |
| 讀取失败 | GitHub 连接问题 | 检查网络，重新点击讀取 |
| 项目列表为空 | HTML 解析失败 | 检查 travel-content.js 格式 |
| 上傳失敗（401） | PAT 过期或无权限 | 生成新 PAT，确保有 `repo` 权限 |
| 上傳失敗（422） | 文件格式不匹配 | 检查 GitHub 上的文件结构 |
| 预览不更新 | JavaScript 错误 | 打开控制台（F12）检查错误 |
| 草稿丢失 | localStorage 被清空 | 同步前必须上傳 |
